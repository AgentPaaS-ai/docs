# AgentPaaS 0.4.0

Current brew cask. `agentpaas version` shows `CLI: 0.4.0`.

## Added

- MCP and tool deployments
- Signed cloud workflows: linear, fan-out (join all), choice (fail-closed), phone-call (depth 1)
- Read-only console: Components, Workflows, Deployments, Runs, Logs
- Cron named minimum every 5 minutes
- Ingress, completion, and delivery webhooks via Hermes or the API
- File inputs (50 MiB) and URL inputs for packed hosts
- Trial: 5 agents, 5 tools, 5 MCP live; unlimited workflow recipes; 10 concurrent runs

The weather trial remains a single-agent run. A workflow is a recipe, not a deployment.

## Not in 0.4

Native HITL, join-any, for-each, wait/delay, Windows/Linux local runtime, open signup, OpenAI/Anthropic as the stranger cold path.
