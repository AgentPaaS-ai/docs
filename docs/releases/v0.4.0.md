# Release 0.4.0

AgentPaaS 0.4.0 adds the cloud component registry, MCP and tool deployments, signed workflow envelopes, workflow runs, console object pages, cron, file pointers through stages, bounded transient retry, handoff artifacts, webhooks through the API, invoke tokens, and metadata-first cloud pull.

The weather trial remains a single-agent run. Workflow kinds are linear, fan-out, choice, and phone-call. See [platform limits](../trial/platform-limits.md) for unsupported paths and capacity.
