# AgentPaaS v0.5.0 release notes

Release date: 2026-09-20

The OSS repository has a `v0.5.0` tag. The Cloud repository has no matching release tag, so the Cloud scope below is reconstructed from the Cloud main branch and the release boundary used for the 0.5.0 launch. Keep the CLI and Cloud versions aligned when you deploy them together.

## Breaking changes

- Cursor, Claude Code, Grok Build, and `agentpaas-mcp` host integrations are not a supported 0.5.0 documentation path. Hermes remains the documented host. Other hosts can call the CLI when customers configure them independently.

## Upgrade notes

Install the 0.5.0 OSS release, then verify the CLI and daemon versions:

```bash
brew update
brew upgrade --cask AgentPaaS-ai/homebrew-tap/agentpaas
agentpaas version
agentpaas doctor
```

Repack agents whose `agent.yaml` declares an LLM credential. The pack step compiles that credential reference into the signed policy used by the runtime.

## Added

- Durable workflow waiting for live child calls that cannot obtain a copy slot. Cloud returns HTTP `202` with `code: "waiting_seat"` and resumes the child when capacity opens.
- OAuth LLM credentials with gateway-side token exchange and refresh. Access tokens stay in memory and refresh tokens remain in the vault.
- PII guardrails with `mask` and `reject`, built-in detectors for `Email`, `Ssn`, `DriversLicense`, `CreditCard`, and `Key`, plus tenant patterns.
- Gateway-observed LLM token and cost metering in run details and Usage and Plan.
- Signed LLM budgets using `llm_budget.max_tokens`, `llm_budget.max_tokens_per_request`, and `llm_budget.max_cost_usd`.
- Virtual model aliases with availability-only fallback for HTTP `429`, HTTP `5xx`, timeouts, and connection failures.
- Per-tool MCP enforcement from the signed deployment policy.
- CLI policy inspection with `agentpaas policy show` and `agentpaas policy validate`.
- Read-only Cloud policy, deployment, egress decision, digest, and event views.
- Athena policy explanations that identify policy and CLI changes without applying them.
- An OpenAI-compatible local loopback path at `127.0.0.1/v1/chat/completions` for governed framework clients.
- Persisted Cloud API endpoint selection after successful login.
- OpenRouter reasoning effort values `low`, `medium`, `high`, and `max`.

## Changed

- PII inspection buffers a stream or fails closed when `mask` or `reject` applies. Masking occurs before audit persistence.
- MCP `tools/list` and `tools/call` use the signed tool policy. A host allow-list alone does not grant access to every tool.
- The documented customer path remains Hermes plus the AgentPaaS CLI. Other host integrations can be customized by the customer, but they are not verified release paths.

## Deprecated

None recorded for this release.

## Removed

None recorded for this release.

## Fixed

- The CLI remembers the last successful Cloud API URL and clears it on logout.
- LLM credential references compile consistently in pack, policy inspection, and MCP policy validation.
- Long-running LLM completion handling fails closed on provider and RPC timeout conditions.

## Security

- OAuth LLM access tokens are memory-only. Refresh tokens remain in the vault under the required `oauth_llm_rt_` name prefix.
- PII data is masked before it enters the audit event path when `action: mask` is active.
- MCP tool denials occur before the upstream call and are audited.
- Read-only Athena and policy console views use read-scoped access. The console does not edit policy.
- The preview vault remains a preview backend. This release does not make OpenBao-grade isolation claims.

## Known issues

- Cloud has no matching `v0.5.0` tag. Validate Cloud behavior against the deployed Cloud commit when the CLI and Cloud surfaces are released separately.
- A copy-paste Nous Research OAuth configuration is not published yet. The product schema and token exchange are verified, but the provider endpoint, client registration, and required scopes need a provider-specific verification pass.
- Host integrations are intentionally absent from the supported release path. Hermes is the documented host.

## How to use the new features

Inspect a compiled policy:

```bash
agentpaas policy show
agentpaas policy validate
```

Define an LLM budget:

```yaml
llm_budget:
  max_tokens: 100000
  max_tokens_per_request: 8000
  max_cost_usd: "10.00"
```

Restrict MCP tools:

```yaml
mcp_servers:
  - url: https://mcp.example.com
    allowed_tools: [read_issue, list_issues]
    denied_tools: [delete_issue]
```

Configure PII masking, including a custom phone pattern:

```yaml
guardrails:
  pii:
    action: mask
    builtins: [Email, Ssn, DriversLicense, CreditCard, Key]
    patterns:
      - "\\b(?:\\+1[-. ]?)?\\(?[2-9][0-9]{2}\\)?[-. ]?[0-9]{3}[-. ]?[0-9]{4}\\b"
```
