Not needed for the trial. Use the [guided demo](./guided-demo): Hermes installs AgentPaaS via

```text
Install from https://github.com/AgentPaaS-ai/agentpaas
```

Manual brew install is only for advanced repair without Hermes. See the [CLI release notes](/releases/v0.3.7) if you need that path.
